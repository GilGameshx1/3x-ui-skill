## [3.0.0] — 2026-11-08

Порт с Qwen Code на модель-агностичный формат (Hermes Agent / DeepSeek) и
разбор ошибок, найденных на живом сервере.

### 🔐 Секреты

- **Удалена генерация файла-гайда с IP, логином и паролем панели.** Вместо файла
  секрет показывается один раз в чат.
- Убран `echo` сгенерированного пароля в лог и из аргументов команд.
- Все примеры в документации переведены на плейсхолдеры; из `references/ip-migration.md`
  вычищен реальный адрес.
- Добавлен `scripts/check_no_secrets.sh` и CI (`.github/workflows/secrets.yml`):
  публичный IPv4, готовые `vless://`, приватные ключи, `password=...`.

### 🐛 Исправлено

- `x25519` вызывался дважды — приватный и публичный ключи оказывались из разных пар.
  Теперь один вызов + проверка пары через `x25519 -i`.
- Порт и базовый путь панели читались из `/etc/x-ui/x-ui.sh`; теперь из БД
  `settings` (`/etc/x-ui/x-ui.db`).
- Сканер Reality выдавал рекомендации «в стол», в конфиг шёл `google.com:443`.
  Добавлен `references/reality-sni.md` с проверкой TLS 1.3 + h2 и списком кандидатов.
- Замок SSH делался `sed` по `sshd_config`: на закомментированных строках правка
  молча не применялась, `sshd` не проверялся. Теперь drop-in, `sshd -t`, автооткат.
- ICMP гасился правкой `/etc/ufw/before.rules` и терялся при `ufw reset`; теперь
  `sysctl net.ipv4.icmp_echo_ignore_all=1`.
- BBR: добавлена проверка модуля и лечение устаревшего `modules.dep` через `depmod`.
- «Проверка» из `x-ui status` + `ss -tlnp` заменена на сквозной тест
  `scripts/verify_vless.py` (exit IP).

### ✨ Новое

- Режим аудита и ремонта живого сервера (`scripts/server_audit.sh`).
- Режим смены IP (`references/ip-migration.md`): маршрут и `src`, SNAT для docker,
  пересоздание MTProto, LE на IP, чистка старого адреса.
- Таймер автооткатa перед правками SSH/UFW.
- `references/reality-link-format.md` и раздел «Грабли» из практики.

### 🧹 Убрано

- `QWEN.md`, `test.sh` (заменён на `check_no_secrets.sh`), `Allowed Tools`,
  установка в `~/.qwen/skills`.

## [2.0.0] — 2024-03-22

### ✨ Новые возможности

- **Полная русификация** — вся документация переведена на русский язык
- **Валидация входных данных** — проверка IP, имени пользователя, домена перед началом установки
- **Индикаторы прогресса** — визуальное отображение прогресса выполнения ([1/22] ✓)
- **SQLite3 поддержка** — автоматическая установка SQLite3 для базы данных 3x-ui
- **Генерация файла-гайда** — автоматическое создание подробного руководства с учётными данными
- **QWEN.md** — конфигурация активации навыка для Qwen Code

### 🛠️ Новые скрипты

- **rollback.sh** — полный откат всех изменений навыка
- **backup-db.sh** — резервное копирование базы данных SQLite3
- **restore-db.sh** — восстановление базы данных из резервной копии
- **test.sh** — тестирование установки и проверка компонентов (25 тестов)

### 🔧 Улучшения

- **install.sh** — исправлен путь копирования, добавлена цветовая индикация, проверка зависимостей, команда update
- **SKILL.md** — дополнен Step 18A с полным API вызовом для VLESS Reality
- **README.md** — полностью переработан, теперь на русском языке
- **.gitignore** — расширен, игнорирует бэкапы и SSH-ключи

### 📝 Документация

- **QWEN.md** — переведён на русский язык
- **references/vless-tls.md** — переведён на русский язык
- **references/fallback-nginx.md** — переведён на русский язык
- **CONTRIBUTING.md** — руководство для контрибьюторов
- **SECURITY.md** — политика безопасности
- **CHANGELOG.md** — журнал изменений

### 🐛 Исправления
